📚 Fórmulas Utilizadas

Periodo de Retorno Simple (Payback)

Payback = Inversión / Ahorro anual neto

Años que tarda la inversión en recuperarse con el ahorro generado. No considera el valor del dinero en el tiempo.

Valor Actual Neto (VAN)

VAN = -I₀ + Σ [ (Ahorro_t - OM_t - Reemplazos_t) / (1+r)^t ]

Suma de todos los flujos futuros traídos a valor presente. VAN > 0 → el proyecto crea valor.

Tasa Interna de Retorno (TIR)

0 = -I₀ + Σ [ Flujo_t / (1+TIR)^t ]

Tasa de descuento que hace VAN = 0. TIR > tasa de descuento → proyecto rentable.

Costo Nivelado de Energía (LCOE)

LCOE = Σ [ (I_t + OM_t) / (1+r)^t ] / Σ [ E_t / (1+r)^t ]

Costo promedio por kWh generado durante toda la vida del proyecto. LCOE < precio de red → el proyecto es competitivo.
